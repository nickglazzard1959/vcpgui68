===
SDL_ttf INSTALLATION
(Although not immediately obvious, the repo for this contains its
own versions of freetype and harfbuzz. You have to use git to get
submodules recursively to get these.)
===

$ cd ~/sdl2

$ git clone https://github.com/libsdl-org/SDL_ttf -b SDL2

$ cd SDL_ttf/

$ git submodule update --init --recursive

$ mkdir build

$ cd build

$ ../configure

$ make

$ sudo make install

===
END SDL_ttf INSTALLATION
===

===
SDL_gfx INSTALLATION
(Only the original "ferzkopp" version should be used. There are variations
on Github, but these have gratuitously renamed functions and may have other
issues. The "good" version can only be fetched as a tar file.)
===

$ cd ~/sdl2

$ wget http://www.ferzkopp.net/Software/SDL2_gfx/SDL2_gfx-1.0.4.tar.gz

$ tar xzf SDL2_gfx-1.0.4.tar.gz

$ rm SDL2_gfx-1.0.4.tar.gz

$ mv SDL2_gfx-1.0.4 SDL2_gfx

$ cd SDL2_gfx/

$ ./configure

$ make

$ sudo make install

===
END SDL_gfx INSTALLATION
===

===
VCPGUI installation
===

$ cd ~

$ mkdir vcpgui68

$ cd vcpgui68

$ git clone ssh://nick@mac1.hccc.net/home/nick/gitprojects/vcpgui68

$ cd vcpgui68

$ wget https://github.com/CLIUtils/CLI11/releases/download/v2.7.2/CLI11.hpp

$ sudo apt install libusb-1.0-0-dev

$ ./build.sh

$ wget https://github.com/jgm/pandoc/releases/download/3.11/pandoc-3.11-1-amd64.deb

$ sudo apt install ./pandoc-3.11-1-amd64.deb

$ sudo apt install texlive-full

$ ./builddoc.sh

===
END VCPGUI installation
